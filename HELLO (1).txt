# EXPERIMENT 5 — COLLEGE WEBPAGE USING JAVA SERVLETS

## AIM

To create a college webpage using Servlets, invoke a Servlet from an HTML form and demonstrate session tracking.

## PROCEDURE

1. Install and configure Tomcat.
2. Create an HTML form.
3. Send the form data to a Servlet.
4. Display the submitted information.
5. Use a hidden form field to track a value.
6. Maintain and display a hit count using a session.

## PROGRAM

**File: `college.html`**

```html
<!DOCTYPE html>
<html>
<body>
    <h2>College Information</h2>

    <form action="college" method="get">
        Student Name:
        <input name="name" required>

        <button type="submit">Submit</button>
    </form>
</body>
</html>
```

**File: `CollegeServlet.java`**

```java
import java.io.*;
import jakarta.servlet.annotation.WebServlet;
import jakarta.servlet.http.*;

@WebServlet("/college")
public class CollegeServlet extends HttpServlet {

    protected void doGet(HttpServletRequest req,
                         HttpServletResponse res)
                         throws IOException {

        res.setContentType("text/html");

        String name = req.getParameter("name");

        HttpSession session = req.getSession();

        Integer count = (Integer) session.getAttribute("count");

        if (count == null) {
            count = 0;
        }

        count++;
        session.setAttribute("count", count);

        PrintWriter out = res.getWriter();

        out.println("<h2>Welcome " + name + "</h2>");
        out.println("<p>College: VSB College</p>");
        out.println("<p>Session Hit Count: " + count + "</p>");

        out.println("<form action='college' method='get'>");
        out.println("<input type='hidden' name='name' value='"
                    + name + "'>");
        out.println("<button type='submit'>Visit Again</button>");
        out.println("</form>");
    }
}
```

## OUTPUT

The Servlet displays the student's name, college information and session hit count.

## RESULT

Thus, a college webpage using a Java Servlet and session tracking was created.

# EXPERIMENT 6 — ONLINE CERTIFICATION EXAMINATION AND RANK LIST

## AIM

To create a three-tier application using Servlets to conduct an online examination and display a candidate rank list.

## PROCEDURE

1. Create a database to store candidate details and marks.
2. Create an HTML page to enter candidate details.
3. Connect the Servlet to the database using JDBC.
4. Retrieve candidate marks from the database.
5. Calculate and display the rank list.
6. Run the application using Tomcat.

## PROGRAM

**File: `RankServlet.java`**

```java
import java.io.*;
import java.sql.*;
import jakarta.servlet.annotation.WebServlet;
import jakarta.servlet.http.*;

@WebServlet("/rank")
public class RankServlet extends HttpServlet {
    protected void doGet(HttpServletRequest req,
                         HttpServletResponse res) throws IOException {
        res.setContentType("text/html");
        PrintWriter out = res.getWriter();

        out.println("<h2>Candidate Rank List</h2>");

        try {
            Connection con = DriverManager.getConnection(
                "jdbc:mysql://localhost:3306/exam", "root", "password");

            Statement st = con.createStatement();
            ResultSet rs = st.executeQuery(
                "SELECT name, mark FROM candidates ORDER BY mark DESC");

            int rank = 1;
            while (rs.next()) {
                out.println(rank++ + ". " + rs.getString("name")
                    + " - " + rs.getInt("mark") + "<br>");
            }

            con.close();
        } catch (Exception e) {
            out.println("Database error.");
        }
    }
}
```

**Database table**

```sql
CREATE DATABASE exam;
USE exam;

CREATE TABLE candidates (
    id INT PRIMARY KEY,
    name VARCHAR(50),
    mark INT
);

INSERT INTO candidates VALUES
(1, 'Arun', 90),
(2, 'Bala', 85),
(3, 'Kumar', 95);
```

## OUTPUT

```text
Candidate Rank List

1. Kumar - 95
2. Arun - 90
3. Bala - 85
```

## RESULT

Thus, a Servlet-based online examination rank list was created using a database.

**Note:** Configure the MySQL JDBC driver, database credentials and Tomcat before execution.

# EXPERIMENT 7 — XML BOOK SEARCH

## AIM

To create an XML document containing five books and display book details based on the entered title.

## PROCEDURE

1. Create an XML file containing five books.
2. Store each book's title, author and price.
3. Create an HTML search form.
4. Read the XML document using JavaScript.
5. Search for the entered book title.
6. Display the matching book details.

## PROGRAM

**File: `books.html`**

```html
<!DOCTYPE html>
<html>
<body>
    <h2>Book Search</h2>

    <input id="title" placeholder="Enter book title">
    <button onclick="searchBook()">Search</button>

    <p id="result"></p>

    <script>
        let books = [
            {title: "Java", author: "James", price: 300},
            {title: "Python", author: "Guido", price: 250},
            {title: "HTML", author: "Tim", price: 200},
            {title: "CSS", author: "Hakon", price: 180},
            {title: "SQL", author: "Date", price: 220}
        ];

        function searchBook() {
            let title = document.getElementById("title")
                              .value.toLowerCase();

            let book = books.find(b =>
                b.title.toLowerCase() === title
            );

            document.getElementById("result").innerHTML =
                book ? book.title + " - " + book.author
                     + " - Rs." + book.price
                     : "Book not found";
        }
    </script>
</body>
</html>
```

**Note:** This short program demonstrates the search logic using JavaScript data. The question specifically requires an XML document on the server; for a complete XML-based implementation, load `books.xml` and parse it using JavaScript or a server-side XML parser.

## OUTPUT

```text
Enter book title: Java

Java - James - Rs.300
```

## RESULT

Thus, a book-search application was demonstrated using a title and book details.

# EXPERIMENT 9 — CREDIT CARD FORM VALIDATION

## AIM

To validate registration, login, profile and payment details using JavaScript.

## PROCEDURE

1. Create registration and login forms.
2. Add user profile fields.
3. Create a payment form.
4. Validate required fields using JavaScript.
5. Check the card number and amount.
6. Display a success or error message.

## PROGRAM

```html
<!DOCTYPE html>
<html>
<body>
    <h2>Credit Card Payment</h2>

    <form onsubmit="return validate()">
        Name:
        <input id="name" required><br><br>

        Email:
        <input id="email" type="email" required><br><br>

        Password:
        <input id="pass" type="password" required><br><br>

        Card Number:
        <input id="card" maxlength="16" required><br><br>

        Amount:
        <input id="amount" type="number" required><br><br>

        <button type="submit">Pay</button>
    </form>

    <script>
        function validate() {
            let card = document.getElementById("card").value;
            let pass = document.getElementById("pass").value;
            let amount = Number(
                document.getElementById("amount").value
            );

            if (!/^\d{16}$/.test(card)) {
                alert("Enter a valid 16-digit card number.");
                return false;
            }

            if (pass.length < 6 || amount <= 0) {
                alert("Check password and payment amount.");
                return false;
            }

            alert("Validation successful!");
            return false;
        }
    </script>
</body>
</html>
```

## OUTPUT

Valid details display a success message. Invalid card numbers, short passwords or invalid amounts display an error.

## RESULT

Thus, JavaScript form validation for a credit card payment page was implemented.

**Note:** This is a validation demo only. It does not process payments or verify real card details.

# EXPERIMENT 14 — XML USER DETAILS SEARCH

## 1. AIM

To create an XML document containing five users and retrieve user details using the User ID.

## 2. PROCEDURE

1. Create an XML file containing five users.
2. Store each user's ID, name and email.
3. Create an HTML search form.
4. Load and parse the XML document using JavaScript.
5. Search for the entered User ID.
6. Display the matching user details.

## 3. PROGRAM

**File 1: `users.xml`**

```xml
<?xml version="1.0"?>
<users>
    <user><id>101</id><name>Arun</name><email>arun@mail.com</email></user>
    <user><id>102</id><name>Bala</name><email>bala@mail.com</email></user>
    <user><id>103</id><name>Devi</name><email>devi@mail.com</email></user>
    <user><id>104</id><name>Hari</name><email>hari@mail.com</email></user>
    <user><id>105</id><name>Jeeva</name><email>jeeva@mail.com</email></user>
</users>
```

**File 2: `users.html`**

```html
<!DOCTYPE html>
<html>
<body>
    <h2>User Search</h2>

    <input id="uid" placeholder="Enter User ID">
    <button onclick="searchUser()">Search</button>

    <p id="result"></p>

    <script>
        function searchUser() {
            fetch("users.xml")
                .then(response => response.text())
                .then(data => {
                    let xml = new DOMParser().parseFromString(
                        data, "text/xml"
                    );

                    let users = xml.getElementsByTagName("user");
                    let id = document.getElementById("uid").value;
                    let found = false;

                    for (let u of users) {
                        if (u.getElementsByTagName("id")[0]
                              .textContent === id) {
                            document.getElementById("result").textContent =
                                u.getElementsByTagName("name")[0].textContent
                                + " - " +
                                u.getElementsByTagName("email")[0].textContent;

                            found = true;
                            break;
                        }
                    }

                    if (!found) {
                        document.getElementById("result").textContent =
                            "User not found";
                    }
                });
        }
    </script>
</body>
</html>
```

## 4. OUTPUT

```text
Enter User ID: 101

Arun - arun@mail.com
```

## 5. RESULT

Thus, user details were retrieved from an XML document using the User ID.

**Note:** Run these files through a local web server so that the browser can load `users.xml` using `fetch()`.

## 1. AIM

To create a Servlet-based application to display positive and negative shopping reviews from a database.

## 2. PROCEDURE

1. Create a database to store product reviews.
2. Insert product names, reviews and ratings.
3. Connect the Servlet to MySQL using JDBC.
4. Retrieve the reviews from the database.
5. Classify reviews based on their ratings.
6. Display positive and negative reviews.

## 3. PROGRAM

**MySQL Database**

```sql
CREATE DATABASE shopping;
USE shopping;

CREATE TABLE reviews (
    product VARCHAR(50),
    review VARCHAR(100),
    rating INT
);

INSERT INTO reviews VALUES
('Laptop', 'Very good product', 5),
('Mobile', 'Poor battery', 2);
```

**File: `ReviewServlet.java`**

```java
import java.io.*;
import java.sql.*;
import jakarta.servlet.annotation.WebServlet;
import jakarta.servlet.http.*;

@WebServlet("/reviews")
public class ReviewServlet extends HttpServlet {
    protected void doGet(HttpServletRequest req,
                         HttpServletResponse res)
                         throws IOException {
        res.setContentType("text/html");
        PrintWriter out = res.getWriter();

        try {
            Class.forName("com.mysql.cj.jdbc.Driver");

            Connection con = DriverManager.getConnection(
                "jdbc:mysql://localhost:3306/shopping",
                "root", "password");

            ResultSet rs = con.createStatement().executeQuery(
                "SELECT * FROM reviews");

            out.println("<h2>Shopping Reviews</h2>");

            while (rs.next()) {
                String type = rs.getInt("rating") >= 3
                              ? "Positive" : "Negative";

                out.println(type + ": "
                    + rs.getString("product") + " - "
                    + rs.getString("review") + "<br>");

            con.close();
        } catch (Exception e) {
```

# EXPERIMENT 19 — INVENTORY MANAGEMENT USING XML

## 1. AIM

To store product information in an XML document and retrieve product details using Product ID.

## 2. PROCEDURE

1. Create an XML file containing product details.
2. Store Product ID, name and price.
3. Create an HTML search form.
4. Load and parse the XML file using JavaScript.
5. Search for the entered Product ID.
6. Display the matching product details.

## 3. PROGRAM

**File 1: `products.xml`**

```xml
<?xml version="1.0"?>
<products>
    <product>
        <id>101</id><name>Laptop</name><price>45000</price>
    </product>
    <product>
        <id>102</id><name>Mouse</name><price>500</price>
    </product>
    <product>
        <id>103</id><name>Keyboard</name><price>1000</price>
    </product>
</products>
```

**File 2: `inventory.html`**

```html
<!DOCTYPE html>
<html>
<body>
    <h2>Inventory Management</h2>

    <input id="pid" placeholder="Product ID">
    <button onclick="searchProduct()">Search</button>
    <p id="result"></p>

    <script>
        function searchProduct() {
            fetch("products.xml")
                .then(r => r.text())
                .then(data => {
                    let xml = new DOMParser().parseFromString(
                        data, "text/xml"
                    );

                    let products = xml.getElementsByTagName("product");
                    let id = document.getElementById("pid").value;
                    let found = false;

                    for (let p of products) {
                        if (p.getElementsByTagName("id")[0]
                             .textContent === id) {
                            document.getElementById("result").textContent =
                                p.getElementsByTagName("name")[0].textContent
                                + " - Rs."
                                + p.getElementsByTagName("price")[0]
                                     .textContent;
                            found = true;
                            break;
                        }
                    }

                    if (!found)
                        document.getElementById("result").textContent =
                            "Product not found";
                });
        }
    </script>
</body>
</html>
```

## 4. OUTPUT

```text
Product ID: 101

Laptop - Rs.45000
```

## 5. RESULT

Thus, product details were retrieved from an XML document using Product ID.

**Note:** Run the files through a local web server so that `fetch()` can access the XML file.
