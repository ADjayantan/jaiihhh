EXPERIMENT 3
QUESTION

Write a program to implement to recognize a valid arithmetic expression that uses operator +, –, * and /.

AIM

To write a program to recognize a valid arithmetic expression using +, -, * and / operators.

PROCEDURE
Create a C program.
Read an arithmetic expression from the user.
Check whether the expression contains valid operands and operators.
Verify that operands and operators appear in the correct order.
Display whether the expression is valid or invalid.
PROGRAM

Filename: exp3.c

#include <stdio.h>
#include <ctype.h>
#include <string.h>

int main()
{
    char s[100];
    int i = 0, operand = 1, valid = 1, seen = 0;

    printf("Enter expression: ");
    fgets(s, sizeof(s), stdin);

    while (s[i] != '\0' && s[i] != '\n')
    {
        if (isspace(s[i]))
        {
            i++;
            continue;
        }

        if (isdigit(s[i]))
        {
            if (!operand)
                valid = 0;

            while (isdigit(s[i]))
                i++;

            operand = 0;
            seen = 1;
            continue;
        }

        if (strchr("+-*/", s[i]) != NULL && !operand)
            operand = 1;
        else
            valid = 0;

        i++;
    }

    if (operand || !seen)
        valid = 0;

    if (valid)
        printf("Valid Expression\n");
    else
        printf("Invalid Expression\n");

    return 0;
}
Important: Add #include <string.h> along with the header files above because the program uses strchr().

OUTPUT

Input:

Enter expression: 10+20*5

Output:

Valid Expression
RESULT

Thus, the C program was implemented to recognize valid arithmetic expressions using arithmetic operators.





 EXPERIMENT 4: CALCULATOR USING LEX AND YACC

## AIM

To implement a calculator using LEX and YACC to perform arithmetic operations.

## PROCEDURE

1. Create the LEX file `lexer.l` and YACC file `parser.y`.
2. Define patterns for numbers and arithmetic operators in LEX.
3. Define arithmetic operations and precedence rules in YACC.
4. Compile the files using Flex, Bison and GCC.
5. Execute the program and display the calculated result.

## PROGRAM

File 1: lexer.l

```c
%{
#include "parser.tab.h"
#include <stdlib.h>
%}

%%
[0-9]+    { yylval = atoi(yytext); return NUMBER; }
[ \t\n]+  ;
.         { return yytext[0]; }
%%

int yywrap()
{
    return 1;
}
```

### File 2: parser.y

```c
%{
#include <stdio.h>
int yylex(void);
void yyerror(const char *s);
%}

%token NUMBER
%left '+' '-'
%left '*' '/'

%%
input:
    expr { printf("Result = %d\n", $1); }
    ;

expr:
      expr '+' expr { $$ = $1 + $3; }
    | expr '-' expr { $$ = $1 - $3; }
    | expr '*' expr { $$ = $1 * $3; }
    | expr '/' expr { $$ = $1 / $3; }
    | '(' expr ')'  { $$ = $2; }
    | NUMBER        { $$ = $1; }
    ;
%%

int main()
{
    printf("Enter expression: ");
    yyparse();
    return 0;
}

void yyerror(const char *s)
{
    printf("Invalid Expression\n");
}
```


## COMPILATION

```bash
bison -d parser.y
flex lexer.l
gcc parser.tab.c lex.yy.c -o calc -lfl
./calc
```



## OUTPUT

**Input:**

```text
Enter expression: 5+3
```

**Output:**

```text
Result = 8
```

**Another Example:**

```text
Enter expression: 5+3*2
Result = 11
```

## RESULT

Thus, a calculator was implemented successfully using LEX and YACC to perform arithmetic operations.

# EXPERIMENT 7: NFA-BASED TOKEN RECOGNITION

## QUESTION

Write a C program to implement NFAs that recognize identifiers, constants, and operators of the language.

## AIM

To implement a simple NFA-based recognizer for identifiers, numeric constants and operators using C.

## PROCEDURE

1. Create a C program.
2. Read a token from the user.
3. Check the token against identifier, constant and operator patterns.
4. Identify the matching token category.
5. Display the recognized token or an invalid-token message.

## PROGRAM

**Filename: `nfa.c`**

```c
#include <stdio.h>
#include <ctype.h>
#include <string.h>

int main()
{
    char s[50];
    int i, id = 1, num = 1;

    printf("Enter token: ");
    scanf("%49s", s);

    if (isalpha(s[0]) || s[0] == '_')
    {
        for (i = 1; s[i]; i++)
            if (!isalnum(s[i]) && s[i] != '_')
                id = 0;

        if (id)
            printf("Identifier\n");
        else
            printf("Invalid Token\n");
    }
    else if (isdigit(s[0]))
    {
        for (i = 0; s[i]; i++)
            if (!isdigit(s[i]))
                num = 0;

        if (num)
            printf("Constant\n");
        else
            printf("Invalid Token\n");
    }
    else if (strchr("+-*/=<>", s[0]) != NULL && s[1] == '\0')
        printf("Operator\n");
    else
        printf("Invalid Token\n");

    return 0;
}
```

## COMPILATION

```bash
gcc nfa.c -o nfa
./nfa
```

## OUTPUT



```text

```

# EXPERIMENT 8: DFA-BASED TOKEN RECOGNITION

## QUESTION

Write a C program to implement DFAs that recognize identifiers, constants, and operators of a language.

## AIM

To implement a DFA-based recognizer for identifiers, numeric constants and operators using C.

## PROCEDURE

1. Create a C program.
2. Read a token from the user.
3. Define states for identifiers, constants and operators.
4. Process the input characters using state transitions.
5. Display the recognized token category.

## PROGRAM

**Filename: `dfa.c`**

```c
#include <stdio.h>
#include <ctype.h>
#include <string.h>

int main()
{
    char s[50];
    int i, state = 0;

    printf("Enter token: ");
    scanf("%49s", s);

    for (i = 0; s[i]; i++)
    {
        if (state == 0)
        {
            if (isalpha(s[i]) || s[i] == '_')
                state = 1;
            else if (isdigit(s[i]))
                state = 2;
            else if (strchr("+-*/=<>", s[i]) != NULL)
                state = 3;
            else
                state = -1;
        }
        else if (state == 1)
        {
            if (!isalnum(s[i]) && s[i] != '_')
                state = -1;
        }
        else if (state == 2)
        {
            if (!isdigit(s[i]))
                state = -1;
        }
        else if (state == 3)
            state = -1;

        if (state == -1)
            break;
    }

    if (state == 1)
        printf("Identifier\n");
    else if (state == 2)
        printf("Constant\n");
    else if (state == 3 && s[1] == '\0')
        printf("Operator\n");

        printf("Invalid Token\n");

}
```

## QUESTION

Write a program to implement the back end of the compiler which takes the three-address code and produces 8086 assembly language instructions. The target instructions can be simple MOV, ADD, SUB and jump instructions.

## AIM

To implement a simple compiler back end that converts three-address code into 8086-style assembly instructions.

## PROCEDURE

1. Create a C program.
2. Read a three-address code statement.
3. Separate the destination, operands and operator.
4. Generate corresponding MOV, ADD or SUB instructions.
5. Display the generated assembly instructions.

## PROGRAM

**Filename: `backend.c`**

```c
#include <stdio.h>
#include <string.h>

int main()
{
    char tac[100], dest[20], rhs[50];
    char *op;

    printf("Enter TAC (t1=a+b): ");
    scanf("%99s", tac);

    if (sscanf(tac, "%19[^=]=%49s", dest, rhs) != 2)
    {
        printf("Invalid TAC\n");
        return 1;
    }

    op = strpbrk(rhs, "+-");

    if (op)
    {
        char symbol = *op;
        *op = '\0';

        printf("MOV AX, %s\n", rhs);
        printf("%s AX, %s\n",
               symbol == '+' ? "ADD" : "SUB", op + 1);
        printf("MOV %s, AX\n", dest);
    }
    else
        printf("MOV %s, %s\n", dest, rhs);

    return 0;
}
```

## COMPILATION

```bash
gcc backend.c -o backend
./backend
```

## OUTPUT

**Input:**

```text
t1=a+b
```

**Output:**

```text
MOV AX, a
ADD AX, b
MOV t1, AX
```

## RESULT

Thus, a simple compiler back end was implemented to convert three-address code into 8086-style assembly instructions.

# EXPERIMENT 13

## QUESTION

Convert the BNF rules into YACC form and write a program to generate an abstract syntax tree.

## AIM

To implement a parser using YACC to generate an abstract syntax tree (AST) for arithmetic expressions.

## PROCEDURE

1. Create the LEX file `lexer.l` and YACC file `parser.y`.
2. Define tokens for identifiers, numbers and arithmetic operators.
3. Write grammar rules in YACC to parse arithmetic expressions.
4. Construct AST nodes for operands and operators.
5. Compile and execute the program to display the AST.

## PROGRAM

### File 1: `lexer.l`

```c
%{
#include "parser.tab.h"
#include <stdlib.h>
%}

%%
[a-zA-Z][a-zA-Z0-9]* {
    yylval.text = strdup(yytext);
    return ID;
}

[0-9]+ {
    yylval.text = strdup(yytext);
    return ID;
}

[ \t\n]+ ;
. { return yytext[0]; }
%%

int yywrap()
{
    return 1;
}
```

### File 2: `parser.y`

```c
%{
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

typedef struct Node {
    char val[20];
    struct Node *left, *right;
} Node;

Node *root;

Node *make(char *v, Node *l, Node *r)
{
    Node *n = malloc(sizeof(Node));
    snprintf(n->val, sizeof(n->val), "%s", v);
    n->left = l;
    n->right = r;
    return n;
}

void print(Node *n, int d)
{
    int i;
    if (!n) return;

    for (i = 0; i < d; i++)
        printf("  ");

    printf("%s\n", n->val);
    print(n->left, d + 1);
    print(n->right, d + 1);
}

int yylex(void);
void yyerror(const char *s);
%}

%union {
    char *text;
    Node *node;
}

%token <text> ID
%type <node> expr
%left '+' '-'
%left '*' '/'

%%
input:
    expr { root = $1; }
    ;

expr:
      expr '+' expr { $$ = make("+", $1, $3); }
    | expr '-' expr { $$ = make("-", $1, $3); }
    | expr '*' expr { $$ = make("*", $1, $3); }
    | expr '/' expr { $$ = make("/", $1, $3); }
    | '(' expr ')'  { $$ = $2; }
    | ID            { $$ = make($1, NULL, NULL); }
    ;
%%

int main()
{
    printf("Enter expression: ");
    if (yyparse() == 0)
        print(root, 0);

    return 0;
}

void yyerror(const char *s)
{
    printf("Invalid expression\n");
}
```

## COMPILATION

```bash
bison -d parser.y
flex lexer.l
gcc parser.tab.c lex.yy.c -o ast -lfl
./ast
```

## OUTPUT

**Input:**

```text
a+b*c
```

**Output:**

```text
+
  a
  *
    b
    c
```

## RESULT

Thus, an abstract syntax tree was generated successfully using LEX and YACC for an arithmetic expression.

EXPERIMENT 9
QUESTION

Write a program to Implement Simple Code Optimization Techniques using Constant Folding.

AIM

To implement constant folding to evaluate constant expressions during compilation.

PROCEDURE
Create a C program.
Read an assignment containing a constant arithmetic expression.
Identify the two constant operands and operator.
Evaluate the expression at compile-time using constant folding.
Display the optimized expression.
PROGRAM

Filename: folding.c

#include <stdio.h>

int main()
{
    char var, op;
    int a, b, result;

    printf("Enter expression (a=5+3): ");
    scanf(" %c = %d %c %d", &var, &a, &op, &b);

    switch (op)
    {
        case '+': result = a + b; break;
        case '-': result = a - b; break;
        case '*': result = a * b; break;
        case '/':
            if (b == 0)
            {
                printf("Division by zero\n");
                return 1;
            }
            result = a / b;
            break;
        default:
            printf("Invalid operator\n");
            return 1;
    }

    printf("Optimized code: %c = %d\n", var, result);

    return 0;
}
